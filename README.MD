# Учёт ПК и оргтехники

Курсовая работа по предмету «Распределённые системы и программирования». ИС "Учёт оргтехники"

## Возможности
- учёт оргтехники (IP, MAC, владелец, расположение, статус), поиск и фильтры
- справочники подразделений и сотрудников
- пользователи и роли (ADMIN, MANAGER, VIEWER), привязка пользователя к сотруднику
- отчёты и печатные формы: накладная на передачу, акт на списание
- вход с функцией «Запомнить меня»

## Запуск
1. Установить JDK 21+, Maven и MySQL 8.
2. Выполнить `db/schema.sql`, затем `db/seed.sql` (например, в MySQL Workbench).
3. Заменить логин и пароль в файле `config/application.properties` 
4. Запустить: `mvn spring-boot:run`
5. Открыть http://localhost:8081

Тестовые пользователи (создаются при первом запуске): `admin / admin123`,
`manager / manager123`, `viewer / viewer123`.
